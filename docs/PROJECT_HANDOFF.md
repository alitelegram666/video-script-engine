# VIDEO SCRIPT ENGINE — فایل تحویل پروژه برای هوش مصنوعی

> **به هوش مصنوعی‌ای که این فایل را می‌خواند:** این فایل کل پروژه است: هدف، تصمیم‌ها، معماری، وضعیت فعلی، مشکلات شناخته‌شده، نقشهٔ راه و **کد کامل همهٔ فایل‌ها**. قبل از هر پیشنهاد یا تغییر، بخش‌های ۱ تا ۸ را کامل بخوان. کار را از «وضعیت فعلی» ادامه بده، نه از صفر.

نسخهٔ فایل: 2026-10-03 · نسخهٔ پروژه: V2 Cloud · زبان کاربر: فارسی

---

## ۰. قوانین کار با این پروژه (برای AI)

1. **با کاربر فارسی صحبت کن.** کوتاه، صادق و دقیق. اگر چیزی را تست نکرده‌ای، بگو تست نشده.
2. **از صفر بازنویسی نکن.** کد فعلی کار می‌کند و روی سرور تست شده است. تغییرها را کوچک و مشخص بده.
3. **هر تغییر کد را به‌صورت فایل کامل یا diff دقیق بده**، با مسیر فایل. یک تکه کد بدون جای دقیقش نده.
4. **محدودیت‌های سخت کاربر:**
   - **همه‌چیز باید رایگان باشد.** هیچ سرویس پولی‌ای پیشنهاد نکن، مگر اینکه صریحاً بگویی پولی است.
   - **پردازش روی سرور ابری انجام شود.** سیستم کاربر ضعیف است؛ چیزی که روی کامپیوتر کاربر اجرا شود پیشنهاد نکن.
5. **بعد از هر تغییر، روش تست را هم بگو** (دستور curl یا مراحل در مرورگر).
6. اسم مدل‌ها، قیمت‌ها و API ها زود عوض می‌شوند. قبل از اینکه به آن‌ها تکیه کنی، با مستندات رسمی چک کن.

## ۱. هدف پروژه

یک ابزار فارسی برای ساخت **ویدیوی کوتاه** (YouTube Shorts / Reels / TikTok، ۵ تا ۶۰ ثانیه):

```
عنوان + توضیح
  → تحلیل محتوا → کارگردان هوشمند → صحنه‌ها و سبک → کنترل کیفیت → آداپتور مدل
  → اسکریپت + Master Prompt + Shot Prompt برای Veo / Kling / Runway / Luma / Grok
  → نریشن صوتی فارسی + زیرنویس کلمه‌به‌کلمه
  → (کاربر کلیپ‌ها را در Veo یا Kling می‌سازد و آپلود می‌کند)
  → ویدیوی نهایی ۹:۱۶ با نریشن و زیرنویس سوخته
```

قابلیت مستقل دوم: **زیرنویس خودکار فارسی** برای هر ویدیو یا فایل صوتی. اگر متن اسکریپت داده شود، زیرنویس با همان متن اصلاح می‌شود.

**اصل معماری:** ابزار «مغز» کار است (اسکریپت، پرامپت، صدا، زیرنویس، مونتاژ). خودِ تصاویر ویدیو را **نمی‌سازد**؛ آن کار با مدل‌های ویدیویی است. خروجی ابزار به هیچ مدل ویدیویی‌ای قفل نیست (Model Adapter).

## ۲. تصمیم‌های کلیدی و دلیلشان

| تصمیم | دلیل |
|---|---|
| ابزار اختصاصی ساختیم، نه نصب ابزارهای آماده | هیچ ابزار آماده‌ای فارسی + ۵ سبک بصری + قوانین مدت را با هم نداشت. ArcReel سنگین است (Docker، لایسنس AGPL). Short Video Maker فقط صدای انگلیسی دارد و تصویرش را از فیلم‌های آمادهٔ Pexels برمی‌دارد. MoneyPrinterTurbo (حدود ۱۲۸ هزار ستاره) هم با فیلم آماده کار می‌کند، نه با سبک‌های ما. ایدهٔ اصلی این ابزارها را برداشتیم: edge-tts، Whisper، اصلاح زیرنویس با LLM |
| کنترل کیفیت با **کد**، نه با AI | نتیجه‌اش قطعی و قابل اعتماد است |
| زمان‌بندی صحنه‌ها با کد اصلاح می‌شود (`normalizeTimeline`) | مدل‌های زبانی در جمع‌زدن ثانیه‌ها اشتباه می‌کنند |
| متن و صدای فارسی در **مونتاژ** اضافه می‌شود، نه داخل مدل ویدیو | مدل‌های ویدیو حروف فارسی را خراب می‌کنند. پرامپت‌ها صریحاً می‌گویند ویدیو بدون متن و بدون دیالوگ باشد |
| صدای فارسی با edge-tts (صداهای Farid و Dilara) | رایگان است، زمان هر کلمه را می‌دهد و کیفیت خوبی دارد |
| زیرنویس صدای TTS از زمان‌بندی خودِ TTS + هم‌ترازی با متن اسکریپت | نیازی به تشخیص گفتار نیست، متن دقیق است و نقطه‌گذاری حفظ می‌شود |
| تشخیص گفتار با faster-whisper `turbo` به‌صورت int8 روی CPU | مدل `small` فارسی را بد می‌شنید (مثلاً «مفظت»، «هفس»). turbo تقریباً دقیق است و روی ۲ هستهٔ CPU حدود هم‌اندازهٔ طول صدا طول می‌کشد |
| اصلاح زیرنویس Whisper با متن اسکریپت (difflib) | کلمه‌های اشتباه‌شنیده («تاند» → «تند») با متن درست جایگزین می‌شوند و زمان‌بندی حفظ می‌شود |
| مغز متن: Gemini با کلید رایگان AI Studio (پیش‌فرض) | Free Tier مدل‌های Flash رایگان است و فارسی را خوب می‌نویسد |
| حالت بدون کلید (Pollinations) **حذف شد** | در تست برای خروجی‌های بلند خطای 402 می‌داد یا JSON نامعتبر برمی‌گرداند؛ قابل اعتماد نبود |
| «حالت دستی» نگه داشته شد | راه کاملاً رایگان بدون کلید است: پرامپت در ChatGPT یا Gemini رایگان چسبانده می‌شود و JSON جواب برمی‌گردد |
| میزبانی روی pplx.app (Perplexity) | رایگان است، بک‌اند در ابر اجرا می‌شود و به حساب جدید نیازی ندارد. Dockerfile هم برای Hugging Face Space آماده است |
| Veo نسخهٔ رایگان API ندارد | Veo 3.1 Lite ثانیه‌ای ۰٫۰۵ دلار، Fast ثانیه‌ای ۰٫۱۰ دلار، Standard ثانیه‌ای ۰٫۴۰ دلار (قیمت‌های اکتبر ۲۰۲۶). پس ساخت کلیپ‌ها بیرون از ابزار و با انتخاب خود کاربر انجام می‌شود |

## ۳. معماری

```
Browser (static/: index.html, styles.css, engine.js, app.js)
   │  همهٔ درخواست‌ها به ${API}/api/...   (API = 'port/8000' روی pplx.app، '' در اجرای محلی یا HF)
   ▼
FastAPI (app.py)  ── core/llm.py    → Gemini / Groq / OpenRouter / سرویس سازگار با OpenAI (کلید را خود کاربر در هر درخواست می‌فرستد)
                  ── core/audio.py  → edge-tts (TTS)، faster-whisper (ASR)، ffprobe
                  ── core/subs.py   → گروه‌بندی کلمه‌ها، SRT / VTT / ASS، align_to_script
                  ── ffmpeg + libass → اتصال کلیپ‌ها، تبدیل به ۹:۱۶، اضافه کردن نریشن، سوزاندن زیرنویس
Jobs: در حافظه + فایل‌ها در /tmp/vse-jobs/{id}، حذف خودکار بعد از ۳ ساعت، صف کارهای سنگین با ۱ worker
```

### مسیر اسکریپت (`engine.js`، سمت مرورگر)
1. `plan(duration, wps)`: Duration Intelligence. تعداد صحنه‌ها، تعداد کلمه (مدت × سرعت نریشن؛ پیش‌فرض ۲٫۳ کلمه در ثانیه)، حداکثر تعداد نکته، ساختار روایت، سقف طول Hook.
   - ≤۱۰ ثانیه: Hook → Payoff
   - ≤۲۰ ثانیه: Hook → یک ایدهٔ اصلی → Payoff
   - ≤۳۵ ثانیه: ۲ نکته
   - ≤۴۵ ثانیه: ۳ نکته
   - بیشتر: ۴ نکته
2. **Stage 1** (`stage1Prompt`): تحلیل محتوا، Smart Director (هدف، سبک، نوع Hook) و ساختار beatها. خروجی JSON.
3. **Stage 2** (`stage2Prompt`): Scene Engine + Style Bible سبک انتخاب‌شده و Consistency Lock (شخصیت‌ها یک بار تعریف و در همهٔ شات‌ها تکرار می‌شوند). خروجی JSON شامل master، scenes، thumbnail، titles و hashtags.
4. `normalizeTimeline`: اصلاح زمان‌بندی با کد.
5. `qualityCheck`: ۱۱ بررسی. اگر رد شود، یک بار Stage 2 با فهرست ایرادها دوباره اجرا می‌شود (Auto-repair).
6. `adapt(out, model)`: Model Adapter. کلیپ‌ها بر اساس طول‌های مجاز هر مدل تقسیم می‌شوند و قالب پرامپت مخصوص همان مدل ساخته می‌شود.

### سبک‌ها
`Smart`، `Stickman`، `Cinematic`، `PaperCut`، `Pixar3D` (در پرامپت هرگز اسم Pixar یا Disney نمی‌آید)، `Normal`

### طول کلیپ مجاز هر مدل (`MODELS` در engine.js)
- Veo: ۴، ۶ و ۸ ثانیه (بررسی‌شده)
- Kling: ۵ و ۱۰
- Runway: ۵ و ۱۰
- Luma: ۵ و ۹
- Grok: ۶

⚠️ مقدارهای Kling، Runway، Luma و Grok **بررسی نشده‌اند** و باید با مستندات همان مدل چک شوند.

### API بک‌اند
| Endpoint | ورودی | خروجی |
|---|---|---|
| `GET /api/health` | — | وضعیت سرور، مدل‌های ASR بارگذاری‌شده، صداها |
| `POST /api/llm` | JSON: provider, apiKey, model, baseUrl, system, user, temperature | `{ok, data}` (JSON پاسخ مدل) |
| `POST /api/tts` | JSON: text, voice, rate, target, autofit, style, max_words | job + duration + cues + فایل‌ها (mp3, srt, vtt, ass) |
| `POST /api/transcribe` | multipart: file, model (turbo/small/...), language, script, style, max_words | job (پیشرفت را با poll بگیرید) |
| `POST /api/render` | multipart: subs_job, files[] یا use_source, mux_voice, style, max_words | job → final.mp4 |
| `GET /api/job/{id}` | — | status / progress / stage / result / error |
| `GET /api/file/{id}/{name}` | — | دانلود فایل |

خطاهای ارائه‌دهندهٔ LLM با **کد 400** برمی‌گردند. پروکسی pplx.app پاسخ‌های 502 را به یک 503 خالی تبدیل می‌کند، برای همین 502 استفاده نمی‌شود.

### امنیت (بعد از بررسی امنیتی)
- CORS برداشته شده است.
- محدودیت درخواست: ۶۰ درخواست POST در هر ۱۰ دقیقه برای هر IP.
- جلوگیری از SSRF در Base URL سفارشی: فقط https و فقط آدرس‌های عمومی.
- کلید کاربر هیچ‌جا ذخیره نمی‌شود.
- provider `dev` فقط وقتی فعال است که `VSE_DEV=1` باشد؛ در نسخهٔ منتشرشده این متغیر تنظیم نشده است.

## ۴. وضعیت فعلی (اینجا هستیم)

- **نسخهٔ منتشرشده:** https://video-script-engine.pplx.app (عمومی). Site ID: `7edae152-13b6-44fa-9b2a-bf11ee7e2230`
- **روی نسخهٔ منتشرشده تست شده و سالم است:**
  - health
  - TTS فارسی با تنظیم خودکار سرعت (۲۹٫۹ ثانیه برای هدف ۳۰ ثانیه)
  - transcribe با turbo + اصلاح با متن اسکریپت
  - render: اتصال ۶ کلیپ به ۱۰۸۰×۱۹۲۰ با نریشن و زیرنویس سوخته (h264/aac)
  - حالت دستی → QC → پرامپت‌ها → صدا → ویدیو
  - مسیر Gemini تا مرحلهٔ احراز هویت (با کلید نامعتبر، خطای درست از Gemini برگشت)
- **روی سرور آزمایشی تست شده:** اسکریپت‌سازی کامل با یک LLM (آزمایشی) → READY TO GENERATE (۱۰ از ۱۱ بررسی موفق).
- **تست نشده:** اسکریپت‌سازی کامل با **کلید واقعی Gemini** روی نسخهٔ منتشرشده. اسم مدل پیش‌فرض: `gemini-3.5-flash`.

## ۵. مشکلات و محدودیت‌های شناخته‌شده
1. بعد از مدتی بی‌استفادگی، سرور خاموش می‌شود. درخواست اول بعد از آن کند است و مدل Whisper دوباره بارگذاری می‌شود.
2. فایل‌ها و jobها فقط در حافظه و /tmp هستند و ماندگار نیستند. بعد از ۳ ساعت یا ری‌استارت سرور پاک می‌شوند.
3. QC «جا شدن نریشن در صحنه» گاهی هشدار می‌دهد، چون LLM برای صحنهٔ Hook متن زیادی می‌نویسد.
4. سقف تنظیم خودکار سرعت TTS بین ‎-۳۰٪ و ‎+۳۰٪ است. اگر متن خیلی بلند باشد، مدت با هدف جور نمی‌شود.
5. زیرنویس ASS افکت ساده (pop / fade) دارد. هایلایت کلمه‌به‌کلمه (کارائوکه) ندارد.
6. Whisper روی CPU با ۲ هسته: یک ویدیوی ۶۰ ثانیه‌ای حدود ۶۰ ثانیه طول می‌کشد.
7. صداهای فارسی edge-tts فقط دو صداست: Farid (مرد) و Dilara (زن).

## ۶. نقشهٔ راه پیشنهادی (به ترتیب ارزش)
1. **تست با کلید واقعی Gemini.** اگر اسم مدل عوض شده بود، `PROVIDERS` در llm.py را اصلاح کن.
2. **ویرایش زیرنویس در صفحه** (تغییر متن یا زمان هر خط) قبل از سوزاندن.
3. **هایلایت کلمه‌به‌کلمه** در ASS (رنگ کلمهٔ در حال خواندن)، با تست روی متن راست‌به‌چپ.
4. **هم‌ترازی نریشن با صحنه‌ها:** زمان شروع هر صحنه از زمان‌بندی TTS دربیاید و طول کلیپ‌ها همان شود.
5. **ذخیرهٔ پروژه‌ها** (تاریخچه)، با یک دیتابیس رایگان مثل Supabase یا در localStorage مرورگر.
6. **کاور (تامبنیل):** ساخت تصویر از `thumbnail.prompt` با یک مدل تصویر رایگان.
7. **ساخت گروهی:** چند عنوان → چند اسکریپت.
8. موزیک پس‌زمینه با کتابخانهٔ رایگان و کم کردن خودکار صدای موزیک زیر نریشن (ducking با ffmpeg sidechaincompress).

## ۷. اجرا و استقرار
- **محلی:** `pip install -r requirements.txt` (ffmpeg هم لازم است)، بعد `python -m uvicorn app:app --port 8000` و باز کردن `http://localhost:8000`
- **Hugging Face Space (رایگان، CPU Basic با ۲ vCPU و ۱۶ گیگ رم):** یک Space با SDK = Docker بسازید و همهٔ فایل‌ها را آپلود کنید. Dockerfile و هدر README آماده‌اند و پورت 7860 است.
- **فونت:** `fonts/Vazirmatn-Bold.ttf` برای سوزاندن زیرنویس لازم است. این فایل باینری است و در این سند نیامده؛ از https://github.com/rastikerdar/vazirmatn/raw/master/fonts/ttf/Vazirmatn-Bold.ttf دانلود کنید.
- **متغیرهای محیطی:**
  - `VSE_ASR_MODEL`: مدل تشخیص گفتار (پیش‌فرض turbo)
  - `VSE_WARM`: بارگذاری مدل Whisper هنگام شروع سرور (پیش‌فرض 1)
  - `VSE_WORK`: پوشهٔ فایل‌های موقت
  - `VSE_DEV`: فقط برای تست آزمایشی
